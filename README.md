# 공부 시간 측정기 v0.6

알림창에서 공부/휴식을 시작하거나 측정을 중지할 수 있는 Android 프로토타입입니다.
완성된 StudyTimer_v0.6.apk를 기존 앱 위에 업데이트 설치하세요. 기존 앱은 삭제할 필요가 없습니다.
업데이트 후 앱을 한 번 열고 알림 권한을 허용하세요. 알림을 펼치면 조작 버튼이 표시됩니다.

소스 구조와 수정 방법은 CODE_GUIDE.md를 참고하세요.
코드 수정 후 Build-App.cmd 또는 Build-Update.cmd를 실행하면 소스 빌드와 기존 키를 이용한 서명을 수행합니다.
Sign-Update.ps1만 실행하면 이미 빌드된 APK의 서명만 수행합니다.

기능: 공부/휴식 측정, 날짜별 합산 캘린더, 로그 편집·삭제, 시간 중복 방지, 2초 미만 기록 제외, 시작/중지 애니메이션, 알림창 제어.
기록은 기기 내부에만 저장합니다. 강제 종료/재부팅/알림 삭제 후에는 앱을 열어 알림을 복구하세요.

이 소스는 HTML/CSS/JavaScript + Android Java WebView 방식이며 Gradle 프로젝트가 아닙니다.
실제 기기에서의 알림 조작은 아직 미검증입니다.
